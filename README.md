# MEDALI

A character-building app for a campus: mentoring, activities, assessment,
counselling, discipline and dormitory, in one place.

## Getting started

Works on a Mac or on Windows.

1. Install Claude Code: https://claude.com/claude-code
2. Open Claude Code and say:
   "clone https://github.com/zakiarsyad/medali and open it".
3. In that folder, say "set up". Claude installs what is missing and
   starts the app.

## Working on it

Say "spec …" to plan a piece of work, "build" to make it, and "clean up"
when you are done. The rules are in `CLAUDE.md`.

All data in this repo is sample data. No real person's data goes here.
